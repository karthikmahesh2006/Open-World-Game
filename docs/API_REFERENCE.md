# REST & Multiplayer API Reference
- `GET /api/health` — Railway container healthcheck
- `POST /api/multiplayer/sync` — Real-time 3D player position, swimming, vehicle & name tag sync
- `GET /api/multiplayer/players` — List online players
- `POST /api/multiplayer/leave` — Disconnect player
- `POST /api/auth/login` — Authenticate pilot profile
- `POST /api/progress/save` — Save XP, coins, splats & coordinates
